# gametools

A full suite of tools designed to provide:
- [x] Loading Screens
- [x] Start menus
- [x] Save / load system
- [x] Options menus
  - [x] Display settings
  - [x] Sound settings
  - [ ] Gameplay settings (storage only — apply logic is game-specific)
  - [ ] Accessibility settings (storage only — apply logic is game-specific)

---

## Plugin Configuration

When the plugin is enabled a **GameTools** dock appears in the editor (bottom-left by default). It exposes three settings that are stored in `project.godot` via ProjectSettings and read by the autoloads at runtime.

| Setting | Default | Description |
|---|---|---|
| Version file | `res://version.json` | Path to the CI-generated version JSON. Use **…** to browse. |
| Gameplay setting keys | *(empty)* | Keys in the `gameplay` category — stored, not auto-applied. |
| Accessibility setting keys | *(empty)* | Keys in the `accessibility` category — stored, not auto-applied. |

Settings are written to disk immediately on change. You can also inspect or override them directly in **Project → Project Settings → gametools/**.

## Save / Load System

The `SaveManager` autoload is registered automatically when the plugin is enabled.

### Configuration

Set these on `SaveManager` before your first save/load call (e.g. in your game's `_ready`):

```gdscript
SaveManager.max_slots = 5          # default: 3
SaveManager.use_encryption = true  # default: false
SaveManager.encryption_key = "s3cr3t"
SaveManager.version_file_path = "res://version.json"  # default
```

### Version stamping & compatibility

`SaveManager` reads `res://version.json`, which is generated by your CI pipeline:

```json
{
  "version": "pre-alpha: v0.2.4",
  "changes": {
    "Fix": {
      "General": ["Remove bad changelog file."],
      "Ci": ["Change to json."]
    }
  }
}
```

The `version` field is stamped as `game_version` into every new save's meta automatically. The semver is extracted from the string (prefix like `"pre-alpha: v"` is ignored), and **any change in major version** is treated as a breaking change — saves from a different major version get `possibly_incompatible: true` added to their meta when loaded.

```gdscript
var save := SaveManager.load_slot(0)
if save.meta.get("possibly_incompatible", false):
    show_warning("This save was created with an incompatible version.")
```

The flag is non-destructive — it only exists in the returned dictionary, never written to disk. If `version.json` is missing or a save has no `game_version` field, the check is silently skipped.

### Settings (global, one file)

```gdscript
# Save
SaveManager.save_settings({"master_volume": 0.8, "fullscreen": true})

# Load
var settings := SaveManager.load_settings()
```

### Save Slots

```gdscript
# Save — pass custom meta fields your UI needs (playtime, character level, etc.)
SaveManager.save_slot(0, {
    "player_hp": 100,
    "position": Vector2(32, 64),
}, {
    "playtime_seconds": 3600,
    "character_level": 5,
    "map_completion": 0.42,
})

# Load a slot → {meta: {...}, data: {...}}
var save := SaveManager.load_slot(0)
var hp: int = save.data.player_hp

# List all slots (for a save-select screen)
var slots := SaveManager.list_slots()
# [{slot:0, exists:true, meta:{...}}, {slot:1, exists:false, meta:{}}, ...]

# Housekeeping
SaveManager.slot_exists(0)   # → bool
SaveManager.get_slot_meta(0) # → Dictionary (cheap, skips game data)
SaveManager.delete_slot(0)   # → bool
```

## Options Menu

The `OptionsManager` autoload applies settings to the engine immediately and persists them via `SaveManager`. You build your own themed UI; the plugin provides the logic and unstyled widget components.

### Edit session

```gdscript
# When player opens the options menu:
OptionsManager.begin_editing()   # snapshots state for cancel/revert

# When player clicks Apply / OK:
OptionsManager.commit()          # saves to disk

# When player clicks Cancel:
OptionsManager.cancel()          # reverts to snapshot, reapplies previous values
```

### Reading / writing settings directly

```gdscript
OptionsManager.set_setting("display", "window_mode", DisplayServer.WINDOW_MODE_FULLSCREEN)
OptionsManager.get_setting("display", "window_mode", DisplayServer.WINDOW_MODE_WINDOWED)

# Audio bus by name (any bus in your AudioServer layout):
OptionsManager.set_setting("audio", "Master", 0.8)
OptionsManager.set_setting("audio", "Music", 0.5)

# Gameplay / accessibility — stored but not auto-applied; listen to the signal:
OptionsManager.set_setting("gameplay", "difficulty", 2)
OptionsManager.setting_changed.connect(func(cat, key, val):
    if cat == "gameplay": apply_my_gameplay_setting(key, val))
```

### Composable widgets

Drop any of these into your own scene and they wire to `OptionsManager` automatically:

| Scene | Type | Controls |
|---|---|---|
| `widgets/window_mode_picker.tscn` | OptionButton | Windowed / Fullscreen / Borderless |
| `widgets/resolution_picker.tscn` | OptionButton | Common resolutions up to screen native |
| `widgets/vsync_toggle.tscn` | CheckButton | VSync on/off |
| `widgets/fps_limit.tscn` | SpinBox | `@export min_fps`, `@export max_fps` |
| `widgets/bus_volume_slider.tscn` | HSlider | `@export bus_name` (any AudioServer bus) |

```gdscript
# Instance a volume slider for any audio bus:
var slider = preload("res://addons/netpunk.gametools/subsystems/options/widgets/bus_volume_slider.tscn").instantiate()
slider.bus_name = "Music"
add_child(slider)
```

Widgets sync bidirectionally — a `cancel()` call updates all connected widgets automatically via `OptionsManager.setting_changed`.

## Loading Screen

`LoadingManager` is registered as an autoload. Call it from anywhere to trigger a scene transition with a loading screen overlay.

```gdscript
# Transition to any scene — loading screen appears immediately, scene loads in background.
LoadingManager.go_to("res://scenes/level_2.tscn")
```

The loading screen (`loading_screen.tscn`) is a `CanvasLayer` (layer 128) placed directly under `/root`, so it survives the scene transition and disappears when the new scene is ready.

### Background image from save metadata

```gdscript
# On the LoadingScreen node (or set in Inspector):
loading_screen.background_meta_key = "chapter"
loading_screen.backgrounds = {
    "prologue":   preload("res://backgrounds/prologue.png"),
    "chapter_1":  preload("res://backgrounds/ch1.png"),
    "chapter_2":  preload("res://backgrounds/ch2.png"),
}
loading_screen.default_background = preload("res://backgrounds/default.png")
```

The loading screen reads the last-used save slot's meta, looks up `meta["chapter"]` in the dictionary, and shows the matching texture. Falls back to `default_background` when no save exists or no key matches.

### Custom loading screen

Override the scene path before any transition to use your own themed scene (must expose a `set_progress(float)` method):

```gdscript
LoadingManager.loading_screen_scene_path = "res://ui/my_loading_screen.tscn"
```

## Start Menu

Instance `start_menu.tscn` as your game's opening scene. It exposes four signals and shows/hides Continue automatically.

```gdscript
# Connect signals in your game's autoload or a parent scene:
$StartMenu.new_game_requested.connect(_on_new_game)
$StartMenu.continue_requested.connect(_on_continue)   # carries slot_index: int
$StartMenu.load_game_requested.connect(_on_load_game) # show your slot picker here
$StartMenu.quit_requested.connect(get_tree().quit)

func _on_new_game():
    LoadingManager.go_to("res://scenes/new_game.tscn")

func _on_continue(slot_index: int):
    var save := SaveManager.load_slot(slot_index)
    LoadingManager.go_to("res://scenes/game.tscn")
```

The **Continue** button is hidden automatically when no save slots exist.

### Background image from save metadata

Same pattern as the loading screen — set `background_meta_key`, `backgrounds`, and `default_background` in the Inspector or in code:

```gdscript
$StartMenu.background_meta_key = "chapter"
$StartMenu.backgrounds = {
    "prologue":  preload("res://backgrounds/prologue.png"),
    "chapter_1": preload("res://backgrounds/ch1.png"),
}
$StartMenu.default_background = preload("res://backgrounds/default.png")
```
